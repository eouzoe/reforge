- 每條需求一個編號，欄位固定：**描述、動機（原話優先）、驗收標準、現況、關聯**。

## 1. 名詞

| 詞 | 意思 |
|---|---|
| 上游／原版 | `https://github.com/xbxfk-twh/guyuyizhang` 的現有實作（唯讀參考） |
| 重寫版 | 本專案將建立的新客戶端（新程式庫，尚未開工） |

## 4. 需求細節

### A. 工程與架構

#### R-A1 重寫
- **動機（原話）**：「現在就是要重寫阿」。
- **描述**：以新架構建立新客戶端，不做原地漸進式重構；上游原版保留為參考實作與保真度基準。
- **驗收標準**：新程式庫可獨立建置、執行、測試、發佈；不繼承上游的單檔 IIFE 結構與全量重繪模型。
- **現況**：尚未開工；上游共 411 檔／8.4 MB（不含素材）。

#### R-A2 修掉閃爍
- **動機（原話）**：「要修復每一次遊戲內點一個按鍵就閃爍一次的問題」。
- **描述**：畫面更新必須是**節點身分穩定＋細粒度更新**：點按鍵只改動真正變動的文字／屬性，不重建 DOM 子樹。這是渲染模型問題，不是個別 bug（見 `refactor-plan.md` 第 1.2 節的四輪補丁史）。
- **驗收標準**：
  1. 連續快速點擊同一按鍵 20 次，畫面無可見閃爍（螢幕錄影逐幀比對）。
  2. 點擊後 Performance 面板沒有大規模 Layout／Recalculate Style 尖峰。
  3. 圖片元素在互動中不被重新建立（開發者工具中節點 id 不變）。
- **現況**：上游 `js/ui.js` `onChange: () => render()` → `renderInner()` 全量重建；作者已用四輪補丁壓症狀。
- **關聯**：R-A3、R-D4。

#### R-A3 內容與程式解耦
- **動機（原話）**：「要讓ui畫面 人物語音 美術 音樂 畫面 劇情文本 在更新調整的時候 這些東西都是獨立的 改了之後不會影響其他部分」。
- **描述**：把內容拆成獨立內容包（美術／音樂／語音／劇情文本／數值／介面）；引擎只認 **id 與 schema**，不認檔案路徑。任一包更新不需重建引擎，也不影響其他包。
- **驗收標準**：
  1. 替換一張圖／一段文本／一段語音，不需修改任何引擎程式碼。
  2. 只重建被改動的包；其他包的驗證結果與前次完全相同。
  3. 內容包彼此沒有檔案路徑耦合（以 id 互相引用）。
- **現況**：上游部分達成（`data.js` 是資料層），但資產路徑寫死在程式碼（如 `assets/img/${r.img}.png`），文本散落各處。

#### R-A4 模擬核心無 DOM
- **動機**：可測試、可 headless、agent 可斷言（R-D2 的前提）。
- **驗收標準**：核心可在 Bun／Node 下無瀏覽器跑完整局流程；渲染層可整個替換而不動核心。
- **現況**：上游幾乎成立（`game.js` 的 `document` 只有 2 處），但仍有少量 DOM 滲入。

#### R-A5 離線可啟動
- **動機**：現況零相依、可離線；熱更新不得破壞離線能力。
- **驗收標準**：飛航模式下可進入遊戲、讀寫本地存檔、玩已下載內容；無網路時所有雲端功能靜默降級。

### B. 發行與平台

#### R-B1 熱更新自主發佈
- **動機（原話）**：「要繞過taptap 也能自己發佈熱更新」。
- **描述**：內容與程式更新走自建分發（自架 CDN／物件儲存），不依賴平台審核即可推送；平台通路只是其中之一。
- **驗收標準**：推送一個內容包到自建分發點 → 客戶端下次啟動（或輪詢）取得新版本；全流程不經平台後台。
- **現況**：無。目前唯一更新路徑＝重新打包（APK）或重新上傳（TapTap）。上游作者自己的評估：桌面版尚屬規劃（Electron→Steam）。

#### R-B2 桌面端 TapTap 啟動
- **動機（原話）**：「桌面端現在是透過taptap啓動」。
- **描述**：桌面端維持由 TapTap 用戶端啟動的路徑；自發佈熱更新必須與 TapTap 的版本判定機制協調，不能造成平台反覆提示更新。TapTap 對「自更新遊戲」有官方上報機制（`.taptap/meta.json`），見 `platform-taptap.md`。
- **驗收標準**：熱更新後，TapTap 用戶端不再提示「更新遊戲」；`.taptap/meta.json` 版本號與實際內容版本一致。
- **現況**：待確認目前是否已上架 TapTap PC（見 Q-1）。

#### R-B3 多渠道同源
- **描述**：同一份網頁產物可同時發佈到 TapTap（PC／Android）、官網直下、瀏覽器。**待決**：首發支援哪幾個通路。
- **驗收標準**：同一個建置產物（含雜湊）出現在各通路的發佈記錄中；不需為通路各改一份原始碼（平台差異以啟動參數／外殼處理）。

#### R-B4 包體瘦身
- **動機**：現行 APK 249.72 MiB；桌面包 248.72 MiB ZIP（633 檔）。
- **描述**：首包只含引擎＋必要內容；美術／語音按需下載。**待決**：目標上限。
- **驗收標準**：首包（含首章可玩內容）≤ 目標值；冷啟動後可離線玩首章。

#### R-B5 熱更新安全
- **描述**：內容 manifest 以 Ed25519 簽章，客戶端內嵌公鑰驗章；每個檔案校驗雜湊；切換失敗自動回滾上一版本。
- **驗收標準**：竄改任意內容檔案後客戶端拒收；中斷下載後遊戲仍可啟動（舊版）；可手動回滾到上一版。

### C. 內容生產

#### R-C1 劇情文本獨立成包
- **驗收標準**：文本以穩定行 id 存在；場景與文本分離；每行可掛語音 id、表情、鏡頭等屬性；改文本不動程式。

#### R-C2 語音按需下載
- **驗收標準**：語音不進首包；缺語音檔時以文字繼續、不阻塞流程；可依章節分批下載。

#### R-C3 美術／音樂可替換
- **驗收標準**：替換資產檔案（同 id）即可生效，無需改任何程式或設定。

#### R-C4 內容 schema 驗證
- **驗收標準**：每個內容包通過 schema 驗證才能出包；破壞性變更必須升 schema 版本並附遷移。

### D. 開發流程（agent 迴路）

#### R-D1 agent 實時看到熱更新畫面
- **動機（原話）**：「每一次用agent開發時 能夠實時瀏覽電腦上熱更新的畫面」。
- **驗收標準**：agent 能在本機 dev server 上開啟遊戲（網頁／Android 模擬器／桌面），並取得畫面截圖。

#### R-D2 agent 立即互動
- **動機（原話）**：「立刻交互」。
- **驗收標準**：agent 能以程式化操作點擊、輸入、切換場景，並讀取 console 與遊戲狀態（`window` 觀測介面）作斷言。

#### R-D3 三端同一 dev server
- **動機（原話）**：「可能是android studio 可能是網頁 可能是電腦 等等」。
- **驗收標準**：一個 dev server 同時服務瀏覽器、Android 模擬器／真機、桌面外殼；改一行程式碼三端都能熱更新。

#### R-D4 可重現
- **驗收標準**：固定亂數種子＋腳本化輸入 → 同一劇本產生同一結果；可用於 golden 快照比對與回歸。

### E. 資料與合規

#### R-E1 雲地同步
- **動機（原話）**：「要雲地同步」。
- **描述**：存檔同時存在本地與雲端。本地永遠是可玩的真相（離線優先）；雲端負責跨裝置搬移。同步採樂觀並發（revision CAS）；**衝突不自動合併**，保留兩份讓玩家選。
- **驗收標準**：
  1. 離線遊玩→上線後自動同步，不丟進度。
  2. 兩台裝置分歧時，兩份存檔都保留可選，不靜默覆蓋。
  3. 雲端服務不可用時遊戲完全正常。
- **現況**：上游用 TapTap 小遊戲雲存檔 v4（僅小遊戲容器內可用，1 分鐘 1 次上限）；APK／桌面版沒有雲存檔。

#### R-E2 舊存檔碼可匯入
- **驗收標準**：上游格式的存檔碼可在重寫版匯入（含版本與異常輸入校驗）；匯入後進度與上游一致（可用 golden 測試驗證）。

#### R-E3 合規
- **描述**：待釐清需求：是否在中國大陸發行（版號／備案）、防沉迷與實名、隱私政策、廣告合規、平台內容規範。**平台紅線之一**：TapTap 審核規範禁止「過審後以服務端控制切換遊戲內容」（見 `platform-taptap.md`）。
- **驗收標準**：待補。

#### R-E4 帳號體系
- **描述**：**已定（2026-10-18）**：**TapTap 登入＋遊客模式**；自建帳號不做（原 A／B／C 三選項收斂為 A＋遊客）。遊客＝裝置本地的匿名身分：可玩、可存檔、雲同步可用（同機備份）；綁定 TapTap 後跨裝置同步與存檔遷移。PC／Android 用官方 SDK；純網頁先遊客。備忘：非 TapTap 通路的帳號另議（見 refactor-plan D-15）。
- **驗收標準**：不登入可完整遊玩與存檔；遊客綁定後可跨裝置取回存檔；遊客狀態下換機／重裝的遺失風險須有明確提示。

## 6. 邊界與限制

- 上游唯讀；不得修改、不得在其上開發。
- 不抓 264 MB 素材（`assets/img`、`文档/美术试稿`、`文档/美术评稿`、`开发工具/音乐`）。
- 不對作者的線上服務（兌換服務等）做任何寫入操作。
- **未經明確允許，不登入 TapTap、不改動 TapTap 相關資料**（登入流程、後台、帳號、遊戲頁皆禁止）；TapTap CLI 僅作唯讀／離線探索。
- 上游程式碼不再格式化、不改契約。
